  title: Kedota Physiotherapy App API
  version: 1.3.0
  description: >-
    Spesifikasi OpenAPI untuk API produksi aplikasi Kedota Physiotherapy yang
    berjalan di atas Supabase. Dokumen ini mencakup alur autentikasi phone dan
    Google OAuth, manajemen profil, update PIN via Edge Function, verifikasi 
    tanggal lahir, CRUD data profil, update status, dan penghapusan akun.

    Catatan implementasi:
    - PIN di-hash menggunakan SHA-256 sebelum disimpan ke kolom pin_hash.
    - Auth email untuk signup phone menggunakan email asli user (jika valid),
      fallback ke format {digits}@kedota.local.
    - Update PIN untuk forgot PIN flow menggunakan Edge Function (update-pin)
      yang berjalan server-side dengan service-role key aman.
    - Password Supabase Auth disinkronkan setiap kali PIN diperbarui via
      Edge Function atau direct session update.

  /functions/v1/update-pin:
    post:
      tags:
        - Edge Functions
      summary: Update PIN via Edge Function (server-side)
      description: >-
        Supabase Edge Function untuk update PIN secara aman dari client tanpa
        mengekspos service-role key. Berjalan di server-side (Deno runtime).
        
        **Kapan digunakan:**
        - Forgot PIN flow — user tidak punya session aktif
        - Future: admin reset PIN user
        
        **Keamanan:**
        - Validasi JWT token (atau anon key untuk forgot PIN)
        - Service-role key hanya di server-side
        - Cegah user update PIN user lain (jika punya session)
        - Rollback otomatis jika sync auth password gagal
        
        **Alur:**
        1. Validasi Authorization header (JWT atau anon key)
        2. Cek session — jika ada, pastikan profile_id = user.id
        3. Ambil pin_hash lama (untuk rollback)
        4. Update pin_hash di tabel profiles
        5. Sync password ke Supabase Auth via admin.updateUserById
        6. Jika gagal → rollback pin_hash lama
        7. Return success/error response
        
        **Implementasi di client (Flutter):**
        ```dart
        // Service: supabase_auth_service.dart
        // Method: updateUserPin()
        
        // Jika user punya session → direct update
        if (currentUser != null && currentUser.id == profileId) {
          await client.from('profiles').update(...);
          await client.auth.updateUser(...);
        }
        // Jika tidak ada session → Edge Function
        else {
          await dio.post('/functions/v1/update-pin', ...);
        }
        ```
      security:
        - bearerAuth: []
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/EdgeFunctionUpdatePinRequest'

          description: PIN berhasil diperbarui.
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/EdgeFunctionUpdatePinResponse'

          description: Request body tidak valid (missing fields).

            application/json:
              schema:
                $ref: '#/components/schemas/EdgeFunctionErrorResponse'

                error: "Missing required fields: profile_id, new_pin_hash, new_pin"
        '401':
          description: Authorization header tidak valid atau missing.
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/EdgeFunctionErrorResponse'
              example:
                error: "Missing or invalid Authorization header"
        '403':

          content:
